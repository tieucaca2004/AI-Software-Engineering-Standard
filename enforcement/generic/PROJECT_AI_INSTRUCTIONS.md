# ASES Mandatory Project Instructions

This project adopts the AI Software Engineering Constitution (ASES).

Before any work:
1. Read the complete ASES `CONSTITUTION.md` available at the project-approved path.
2. Read `docs/governance/PROJECT_CONTEXT.md`, `docs/governance/APPROVED_DECISIONS.md`, project scope, technical constraints and current milestone.
3. Read `docs/governance/CURRENT_TASK.md` and confirm the task is `Authorized`, including its allowed files/modules and acceptance criteria.
4. Run `python docs/governance/ases/scripts/ases_gate.py check --project-root . --task docs/governance/CURRENT_TASK.md`.
5. Inspect repository status before changing files.

If any required document is missing, inaccessible, incomplete or contradictory, or if the gate blocks, stop the affected work and report the blocker. Do not guess and do not self-authorize.

Follow the Constitution, preserve approved decisions, do not expand scope, do not claim unexecuted tests passed, do not self-approve, and do not officially integrate before explicit Founder acceptance.

At completion, provide evidence and a Milestone Completion Report.
