# ASES Mandatory Instructions

Before working, read the complete ASES `CONSTITUTION.md` (in an adopted project: `docs/governance/ases/CONSTITUTION.md`, or the `snapshot_dir` recorded in `docs/governance/ases.lock.json`) and the target project's approved decisions, scope, constraints and current milestone.

If required governance documents are missing or inaccessible, stop before implementation and report the blocker.

Follow the Constitution. Do not expand scope or alter approved decisions without explicit Founder approval. Do not claim tests passed without execution and evidence. Do not self-approve milestones or officially integrate work before Founder acceptance. Protect secrets, user/runtime data and Git history; never force-push.

Report changed files, commands and tests executed, results, evidence, known issues, deviations and Git status.
