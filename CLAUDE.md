# ASES — Mandatory Claude Code Instructions

@CONSTITUTION.md

Before every task:
- Read the complete Constitution above (not only this summary).
- Read the project's approved decisions, scope, constraints and current milestone.
- Inspect Git status and the relevant code before editing.
- Confirm the authorized scope and acceptance criteria.
- If the Constitution or required project governance documents cannot be read, stop before implementation and report the blocker.

Never change approved architecture, locked decisions, scope, production data, dependencies or unrelated modules without explicit Founder approval. Never claim tests passed without running them. Never self-approve or officially integrate a milestone. Preserve secrets, user/runtime data and remote Git history.

At the end, report exact files changed, commands executed, test results, evidence, remaining risks and Git status. Wait for explicit Founder acceptance before official integration.
